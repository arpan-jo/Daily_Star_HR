# Module Federation spike — host + Todo remote

Phase 0 of the micro-app plan. Proves Re.Pack 5 Module Federation v2 works on
**RN 0.84 / React 19.2.3** before PeopleDesk goes anywhere near a bundler swap.
Nothing here is imported by the app — this directory is throwaway.

Verified against `@callstack/repack@5.3.0`, `@rspack/core@2.1.8`,
`@module-federation/enhanced@2.8.1`.

## What it must prove

1. Re.Pack 5 builds an RN 0.84 app in **release** mode with Hermes on a real device.
2. A remote's screen loads at runtime over HTTP and renders inside the host.
3. `react` and `react-native` resolve as **singletons** — the remote's hooks and
   the host's hooks share one React. This is the failure everyone hits.

If 1 fails, stop: the rest of the plan is unreachable on this RN version.

## Setup

Two apps, generated by the official tools — do not hand-write the native projects.

```bash
cd scratch/mf-spike

# Host
npx @react-native-community/cli init MfHost --version 0.84.0
cd MfHost && npx @callstack/repack-init && cd ..

# Remote
npx @react-native-community/cli init MfTodo --version 0.84.0
cd MfTodo && npx @callstack/repack-init && cd ..
```

Then copy the files from `host/` over `MfHost/` and `remote/` over `MfTodo/`.
`repack-init` already wrote a working `rspack.config.mjs`; the ones here only add
the federation plugin block — diff them, don't blindly overwrite, since the
generated config is version-matched to what you installed.

## Run

```bash
# 1. remote, serving its container to the host
cd MfTodo && npm start -- --port 9000

# 2. host
cd MfHost && npm start
npx react-native run-android      # or run-ios
```

Android emulator reaches the host machine on `10.0.2.2`, not `localhost` — set
`REMOTE_HOST` in `host/rspack.config.mjs` to your LAN IP for a physical device.

## Checks, in order

| # | Check | How |
|---|---|---|
| 1 | Debug build renders remote | Tap "Open Todo" — list appears |
| 2 | Singleton React | Remote uses `useState`; a duplicate React throws "Invalid hook call" immediately |
| 3 | Remote updates without host rebuild | Edit `MfTodo/src/TodoApp.tsx`, restart only the remote's server, reopen the screen |
| 4 | **Release build** | `npx react-native run-android --mode release` — the real gate; dev-server magic is gone here |
| 5 | Hermes | Confirm `hermesEnabled=true` in `android/gradle.properties`, then repeat 4 |

Check 4 is where Re.Pack spikes usually die. Do not report success before it passes.

## Then what

- Passes → Phase 1: extract the host SDK, and the Todo remote becomes the first
  real consumer. `src/modules/micro-apps/todo/todoState.ts` moves across unchanged.
- Fails → keep `kind: 'native'` apps as local lazy modules (what ships today) and
  revisit when Re.Pack supports this RN version.
